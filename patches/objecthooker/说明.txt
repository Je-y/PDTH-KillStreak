防闪退补丁（可选，不要一上来就装）
================================================================

这个目录里的 objecthooker.lua 是 DAHM 框架里的一个文件（不是本模组的一部分）。
只在一种情况下需要它：**对方的游戏在进关卡击杀时直接闪退**。


一、怎么判断需不需要
------------------
对方装好模组后，如果出现：

    · 一打死敌人，游戏直接退回桌面，没有任何报错弹窗
    · 日志 ...\PAYDAY The Heist\logs\main.log 里能搜到这一行：
        WARNING: too many nested hook calls

那就是他用的 DAHM 还没有这道保护，装这个补丁。


二、怎么装（手动替换，3 步）
--------------------------
1. 完全退出游戏（退到桌面）。

2. 先把他的原文件备份 —— 找到：

     ...\PAYDAY The Heist\mods\core\objecthooker.lua

   改名为 objecthooker.lua.原版备份

3. 把本目录里的 objecthooker.lua 复制到 mods\core\ ，替换掉原来那个。

4. 启动游戏，进关击杀试试。


三、装坏了怎么办
----------------
如果替换之后 DAHM 起不来、或者别的模组也开始报错，说明版本不兼容（他的 DAHM
可能比这里的更新）。恢复方法：

    · 删掉 mods\core\objecthooker.lua
    · 把 objecthooker.lua.原版备份 改回 objecthooker.lua

本目录的 objecthooker.lua.orig 是这份补丁基于的原始版本（DAHM 1.18.1.1），
可以拿来对照，但不要直接用它去覆盖别人的（同理，版本可能不同）。


四、它到底改了什么
------------------
DAHM 的 hook 调用器有一个全局的调用深度计数，上限 256 层。
原版代码在超限之后是这样的：

    if d > MAX_FRAMES then
        log("too many nested hook calls, resetting the call frame stack")
        d = 1              -- 只重置记录，然后继续往下调用
    end

也就是说它只是把计数清零、接着递归。只要某个 mod 真的写出了无限递归，游戏就会
一路走到 Lua 栈溢出，进程直接退出，连错误都来不及写进日志。

补丁改成：

    if d > MAX_FRAMES then
        log("too many nested hook calls, refusing the call to unwind the chain")  -- 只记一次
        return             -- 拒绝这一次调用，让调用链逐层自然退回
    end

正常游戏里调用深度通常只有个位数，永远碰不到 256 层，所以**平时完全不影响任何
东西**；只在出事的时候，把「游戏闪退」换成「某个功能这一次没执行」。

这个改动只影响出错后的行为，不改变任何正常路径。


五、DAHM 以后更新了怎么办（重要）
--------------------------------
DAHM 一更新，mods\core 整个目录会被覆盖，这里的东西也跟着没了。**每次更新之后
都要重新判断一次，不要习惯性地把补丁复制回去。**

判断方法：更新完先什么都不装，进关打一枪试试。

  · 不闪退
      → 说明新版已经修了（或者你的环境本来就不触发），补丁不用装。

  · 还是闪退
      → 先别急着覆盖。用记事本打开 mods\core\objecthooker.lua，
        Ctrl+F 搜 "too many nested hook calls"，看这一行的后半句是什么：

          "... refusing the call to unwind the chain"
              新版已经是修好的逻辑了。问题不在这个文件，别再覆盖，
              把日记 logs\main.log 里崩溃那几行发出来看别的方向。

          "... resetting the call frame stack"  （下一行是 d = 1）
              还是老逻辑，可以按上面第二节替换。

          搜不到这一段
              框架代码被重写过了，**绝对不要用这里的文件去覆盖**，
              结构不同会把整个 DAHM 搞坏。把新版这个文件发出来，重新做一份。

补丁本身和 DAHM 版本是绑定的：这里是基于 1.18.1.1 的 objecthooker.lua 改的，
只能套在结构一致的文件上。


六、怎么知道自己的 DAHM 是哪个版本
-------------------------------
打开 mods\init.lua，开头几行有：

    framework_version = "1.18.1.1"
    expected_hook_revision = 16

如果版本号和上面不同，说明你手上的 DAHM 和这里的不一样，按第五节的办法判断，
不要直接覆盖。
